## Como interpretar o histórico

Commits são agrupados pela data de autoria registrada no Git e alcançáveis pelo commit de referência. Issues são agrupadas pelo fechamento convertido para America/Bahia. A ausência de commit não prova ausência de atividade. A presença de código hoje não prova que ele existia em um ponto de controle anterior. [Metodologia e fontes](../fontes/index.md).
